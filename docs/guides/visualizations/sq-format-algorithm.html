0. SQ-Format 统一框架

SQ-format 是一种混合精度稀疏量化格式，核心思想：

  • 将矩阵按 bank 分组，每个 bank 内固定 (1−s)·b 个元素用高精度 (hhigh)，其余 s·b 个用低精度 (hlow)
  • SQ-format 只作用于 matmul 的一个操作数（权或激活），另一个用普通 uniform 格式
  • 是 NVIDIA 2:4 半结构化稀疏的泛化 (2:4 = s=0.5, hlow=0, b=4)
SQ-format(𝐗) = ([𝐗quant], [𝐒quant], [𝐦], hhigh, hlow, b, s)
等效比特数: y = (1−s) × hhigh + s × hlow
参数含义本文示例
bbank size — 每 bank 包含的行数（沿输入通道轴）4
ssparsity — 低精度元素占比0.5
hhigh高精度格式INT8 (对称, 量程 -127~127)
hlow低精度格式INT4 (对称, 量程 -7~7)
vmask低精度格式中未使用的最大整数值，作为高精度哨兵15 (INT4 无符号表示)
高精度 (INT8)
低精度 (INT4)
vmask 哨兵

GPTQ 重要性打分
对每个权重元素，计算其量化重要性分数。综合了权重自身幅度和模型对其扰动的敏感度。
Ir,i = (W'r,i)² / (H⁻¹i,i)²

含义：
  • (W')² 大 → 绝对值大的权重量化扰动影响大
  • 1/(H⁻¹)² 大 → loss 曲率陡峭方向上权重量化敏感度高
  • 两者相乘 → 综合"谁最不该被低精度量化"

分组量化
将 W' 按 mask 分为两组，各自独立做对称均匀量化。高精度组用 INT8，低精度组用 INT4。
高精度组: (𝐰'high, 𝐬'high) ← Quant(𝐖' ⊙ 𝐦, hhigh)   选取 𝐦=True 的元素，scale = max|𝐰'high| / 127,   wq = round(w' / scale)
低精度组: (𝐰'low, 𝐬'low) ← Quant(𝐖' ⊙ ∼𝐦, hlow)   选取 𝐦=False 的元素，scale = max|𝐰'low| / 7,   wq = round(w' / scale)

注意：⊙ 𝐦 不是逐元素乘法（那样会把非选中元素清零），而是"选取 mask 中为 True 的元素"。
两组各自独立计算 scale 和量化，互不影响。

15 = vmask 哨兵，表示"此处取高精度值"

vmask 机制详解：

  • INT4 对称量化，合法整数值范围：{-7, -6, ..., 6, 7}，共 15 个值
  • 4 bit 可表示 16 个值 (0~15 无符号)，剩余 1 个值 15 (0b1111) 未被使用
  • 用 15 作为哨兵 = "这个位置的高精度真值存在 Whigh 里"
  • 硬件检测到 Wlow 中的 15 → MUX → 从 Whigh 取对应值 → 送入高精度 Tensor Core
  • 类似地，若 hlow=INT2，合法值 {-1, 0, 1}，vmask = 2
硬件执行模型 (Figure 2a)
推理时，两条并行计算路径同时执行，低精度路径吞吐高，高精度路径因稀疏其时延被隐藏。
Path 1: 低精度 (Dense)

𝐖low [8×4] × 𝐀 [8×M]
→ 低精度 Tensor Core (INT4 matmul)
→ 高吞吐 (W4A4 级)
vmask 位置（值=15）在低精度乘法中不参与计算——硬件将其视为 0，由高精度路径补偿

Path 2: 高精度 (Sparse)

① 检测 𝐖low 中的 vmask=15
② MUX 选出对应 𝐀 的行 (共 (1-s)K=4 行)
③ 𝐖high [4×4] × 𝐀selected [4×M]
→ 高精度 Tensor Core (INT8 matmul)
因 2x 稀疏，时延被 Path 1 完全隐藏

Y = Low Result + High Result
为什么高精度路径时延能被隐藏？ 假设 INT4 Tensor Core 算力是 INT8 的 2×，则 Path 1 处理 8 行 INT4 的时间 = Path 2 处理 4 行 INT8 的时间。当 s ≥ 0.5 时，高精度元素 ≤ 一半，其计算量总 ≤ 低精度路径。

2. Algorithm 2: SQ-format on Activations (Static)

场景：激活使用 SQ-format（混合 INT8/INT4），权重使用普通 INT4。记为 W4A(SQ6)。
核心差异：激活值是运行时动态产生的，不能预先量化，但可以用标定集预计算 mask。

Per-channel 重要性打分 (A·W Product)
对每个输入通道 j，计算其对 dot product 的总贡献。不能只用 |Ā_j|，因为激活大的通道若乘以零权重，对结果无影响。
Ij = |Āj · Σi W'j,i|    ∀j ∈ bank

其中：
  • W'j,i：第 j 行第 i 列的权重（注意：没有对 W' 取绝对值！）
  • Σi W'j,i：通道 j 与所有输出特征的权重之和（保留符号）
  • Āj：通道 j 的平均激活幅度
  • |·|：对整个乘积取绝对值
ADR-014 勘误
ADR-014 描述为"连接权重绝对值之和" (Σ|W'|)，但论文公式是 Σi W'j,i（不对 W' 元素取绝对值）。符号信息在求和时是有意义的——正负权重可能相互抵消，表明该通道对输出的净贡献小。取绝对值会丢失这个信息。

  in_1: round(3.60/0.5143) = 7,  in_3: round(−1.98/0.5143) = −4
为什么权重也要分两组量化？ 虽然 SQ-format 作用在激活侧，但为了让两条计算路径的精度匹配，权重也需要按同样的通道分组分别量化。HIGH 通道的权重用 INT8（与 INT8 激活相乘），LOW 通道的权重用 INT4（与 INT4 激活相乘）。注意：此处 mask 是 per-channel 的，因此同一行的所有列用同一精度量化——这与 Algorithm 1 的 per-element mask 不同。
与 Algorithm 1 的量化差异
Algorithm 1 中，mask 是 per-element 的，同一行不同列可能分属不同精度组，因此 scale 也是 per-column 的。Algorithm 2 中，mask 是 per-channel 的，整行统一精度，但不同行的数值范围不同，scale 仍然需要 per-column per-precision-group 计算。
权重行重排 (关键步骤)
将 W' 的行按照 mask 重排，使每个 bank 内高精度通道聚集在前、低精度通道聚集在后。这使得推理时可以用连续内存访问，而非 scatter/gather。

重排规则：在每个 bank 内，将 HIGH 通道对应的行移到前面，LOW 通道对应的行移到后面。不同 bank 之间不交叉重排。

重排的物理意义：

  • 数据局部性：推理时高/低精度计算各取一段连续内存，无需 scatter/gather
  • 硬件友好：GPU Tensor Core 偏好连续内存访问，重排后两条路径可高效并行
  • 存储开销极小：只需存储 per-channel 1-bit mask。Llama-3-70B 仅 5.94 MB
  • 一次性操作：重排在 PTQ 阶段完成，推理时无需任何额外开销

重排带来的关键优势：如果没有重排，高/低精度通道在 𝐖' 中交错排列，硬件需要 gather 操作来选取非连续的行。重排后，每个 bank 内 H 行和 L 行各自连续，硬件只需做简单的切片操作 (slice)——这在 GPU 上可以高效实现。
SmoothQuant 对激活的影响：SmoothQuant 将激活的 outlier 通过 S 缩放迁移到权重侧。推理时，激活 A 需要除以 S（即 𝐀 = 𝐀raw / 𝐒），而权重已经乘以 S（𝐖' = 𝐒 · 𝐖）。因此，上面的 𝐀 是 SmoothQuant 缩放后的激活，其通道幅度分布已经比原始激活更均匀，这使得 per-channel 的 H/L 分组更有效。

Algorithm 2 动态策略 (对比)

静态策略需要标定集预计算 mask，而动态策略在推理时对每个激活 tensor 做 per-bank TopK，按 |A| 绝对值选 top-(1−s) 通道。

静态策略 (Algorithm 2)
  • Mask 在 PTQ 阶段预计算，存储为 per-channel 1-bit 向量
  • 推理时只需查表 + 激活切片
  • 存储开销极小 (Llama-3-70B 仅 5.94 MB)
  • 权重可在 PTQ 阶段按 mask 重排
  • 适合 GPU 部署
动态策略
  • 推理时对每个激活 tensor 做 per-bank TopK（按 |A|）
  • 无需标定集，mask 自适应每个输入
  • TopK 引入额外时延，需专用硬件流水线单元 (Figure 4)
  • 权重无法预先重排（mask 动态变化）
  • 需要专用 AI 加速器支持
动态策略为什么用 |A| 而不是 A·W？ 动态策略在推理时执行，无法访问权重 W（W 在 Tensor Core 中计算）。因此只能用 |A| 绝对值作为重要性指标。这也是论文推荐静态策略的原因之一——静态策略能利用 A·W 信息生成更准确的 mask。

在仔细对比 ADR-014 与论文原文后，发现以下差异和需要注意之处：

最重要的勘误：Σ|W'| vs ΣW'

论文公式 Ij = |Āj · Σi W'j,i| 中，Σi W'j,i 是带符号求和，不是对绝对值求和。这在实际中会产生显著差异：

  • 若通道 j 的权重正负抵消（如本例 ch 2: Σ = −1.35），说明该通道对输出的净贡献小
  • 若取绝对值求和 (Σ|W'|)，则正负不抵消，会高估该通道的重要性
  • 论文明确指出只用 |Ā| 就会导致 "significant performance degradation"，而 Σ|W'| 同样会丢失符号抵消信息
