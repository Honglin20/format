# 018: Per-Tensor + Sparse (Outlier Ratio) 量化正确性

**对应测试函数**: `test_per_tensor_sparse_int8_bit_exact`
**验证层级**: Layer 1（核心量化）

## 格式原理

Per-Tensor + Sparse: 将 tensor 按 magnitude 分为 top-k 离群组和正常组，两组各自独立计算 per-tensor amax，独立量化后合并。

- format: int4
- granularity: per_tensor
- outlier_ratio: 0.25
- scale_storage: pot
- round_mode: nearest

### Int4 量化公式

int4 为 sign-magnitude 格式：mbits=4, ebits=0, max_norm=1.75。

```
elemwise_quant(x):
  scaled = |x| * 4
  rounded = sign(x) * floor(scaled + 0.5)
  clamped = clamp(rounded / 4, -1.75, 1.75)
```

量化等级：±{0, 0.25, 0.5, 0.75, 1.0, 1.25, 1.5, 1.75}

## 给定数据

```python
x = torch.tensor([0.5, 1.0, 10.0, 0.25])
```

## 手工推导

### 无 Sparse（对照组）

```
N = 4
amax = max(|0.5|, |1.0|, |10.0|, |0.25|) = 10.0
pot: amax = 2^round(log2(10.0)) = 2^3 = 8.0

x_norm = x / 8.0 = [0.0625, 0.125, 1.25, 0.03125]

elemwise:
  0.0625:  |4*0.0625|=0.25,  floor(0.25+0.5)=0,       -> 0 / 4 = 0.0
  0.125:   |4*0.125|=0.5,    floor(0.5+0.5)=1,        -> 1 / 4 = 0.25
  1.25:    |4*1.25|=5.0,     floor(5.0+0.5)=5,        -> 5 / 4 = 1.25
  0.03125: |4*0.03125|=0.125, floor(0.125+0.5)=0,      -> 0 / 4 = 0.0

x_q_elemwise = [0.0, 0.25, 1.25, 0.0]

x_q = x_q_elemwise * 8.0 = [0.0, 2.0, 10.0, 0.0]
```

**期望值（无 sparse）: `[0.0, 2.0, 10.0, 0.0]`**

### 有 Sparse（outlier_ratio=0.25）

```
k = max(1, int(4 * 0.25)) = 1
magnitudes: [0.5, 1.0, 10.0, 0.25]
top-1: index 2 (value 10.0, |10.0|=10.0)

mask: [F, F, T, F]
Outlier group:  [     _,      _,  10.0,     _]  在 index 2
Normal group:   [0.5, 1.0,     _, 0.25]       在 index 0,1,3

amax_o = max(|10.0|) = 10.0  -> pot = 8.0
amax_n = max(|0.5|, |1.0|, |0.25|) = 1.0  -> pot = 1.0
```

#### 离群组量化

```
x_o = 10.0
x_o_norm = 10.0 / 8.0 = 1.25
|4*1.25| = 5.0, floor(5.0+0.5) = 5 -> 5/4 = 1.25
x_q_o = 1.25 * 8.0 = 10.0
```

#### 正常组量化

```
x_n = [0.5, 1.0, 0.25]
x_n_norm = [0.5, 1.0, 0.25] / 1.0 = [0.5, 1.0, 0.25]

0.5:   |4*0.5|=2.0,  floor(2.0+0.5)=2 -> 2/4=0.5
1.0:   |4*1.0|=4.0,  floor(4.0+0.5)=4 -> 4/4=1.0
0.25:  |4*0.25|=1.0, floor(1.0+0.5)=1 -> 1/4=0.25

x_q_n_elemwise = [0.5, 1.0, 0.25]
x_q_n = [0.5, 1.0, 0.25] * 1.0 = [0.5, 1.0, 0.25]
```

#### 合并

```
按 mask 合并: [0.5, 1.0, 10.0, 0.25]
```

**期望值（有 sparse）: `[0.5, 1.0, 10.0, 0.25]`**

## 对比总结

| 元素 | 原始值 | 无 Sparse | 有 Sparse |
|------|--------|-----------|-----------|
| x[0] | 0.5 | **0.0** (被压碎) | 0.5 (保留) |
| x[1] | 1.0 | **2.0** (偏差大) | 1.0 (保留) |
| x[2] | 10.0 | 10.0 | 10.0 |
| x[3] | 0.25 | **0.0** (被压碎) | 0.25 (保留) |

Sparse 将离群点 10.0 隔离后，正常组的 scale 从 8.0 降到 1.0，使小值能被正确量化。
