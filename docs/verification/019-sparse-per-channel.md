# 019: Per-Channel + Sparse (Outlier Ratio) 量化正确性

**对应测试函数**: `test_per_channel_sparse_int8_bit_exact`
**验证层级**: Layer 1（核心量化）

## 格式原理

Per-Channel + Sparse: 在每个 channel 内独立做 top-k 分割为离群组和正常组，两组各自独立计算 per-channel amax，独立量化后合并。

- format: int4
- granularity: per_channel (axis=0)
- outlier_ratio: 0.25
- scale_storage: pot
- round_mode: nearest

## 给定数据

```python
x = torch.tensor([[0.5, 10.0, 0.25, 1.0],    # channel 0
                  [2.0, -8.0, 3.0, 1.5]])     # channel 1
# shape: (2, 4), channel_axis=0, C=2, N_per_channel=4
```

## 手工推导

### 无 Sparse（对照组）

```
Channel 0: [0.5, 10.0, 0.25, 1.0]
  amax[0] = max(|0.5|, |10.0|, |0.25|, |1.0|) = 10.0 -> pot = 8.0
  x_norm = [0.5, 10.0, 0.25, 1.0] / 8.0 = [0.0625, 1.25, 0.03125, 0.125]

  0.0625:  |4*0.0625|=0.25,  floor(0.25+0.5)=0     -> 0
  1.25:    |4*1.25|=5.0,     floor(5.0+0.5)=5      -> /4=1.25
  0.03125: |4*0.03125|=0.125, floor(0.125+0.5)=0    -> 0
  0.125:   |4*0.125|=0.5,    floor(0.5+0.5)=1      -> /4=0.25

  x_q[0] = [0.0, 1.25*8=10.0, 0.0, 0.25*8=2.0]
         = [0.0, 10.0, 0.0, 2.0]

Channel 1: [2.0, -8.0, 3.0, 1.5]
  amax[1] = max(|2.0|, |-8.0|, |3.0|, |1.5|) = 8.0 -> pot = 8.0
  x_norm = [2.0, -8.0, 3.0, 1.5] / 8.0 = [0.25, -1.0, 0.375, 0.1875]

  0.25:   |4*0.25|=1.0,   floor(1.0+0.5)=1   -> /4=0.25
  -1.0:   |4*(-1.0)|=4,   floor(4+0.5)=4     -> sign*(-4)/4 = -1.0
  0.375:  |4*0.375|=1.5,  floor(1.5+0.5)=2   -> /4=0.5
  0.1875: |4*0.1875|=0.75, floor(0.75+0.5)=1  -> /4=0.25

  x_q[1] = [0.25*8=2.0, -1.0*8=-8.0, 0.5*8=4.0, 0.25*8=2.0]
         = [2.0, -8.0, 4.0, 2.0]
```

**期望值（无 sparse）: `[[0.0, 10.0, 0.0, 2.0], [2.0, -8.0, 4.0, 2.0]]`**

## 对比总结

| Channel | 位置 | 原始值 | 无 Sparse | 有 Sparse |
|---------|------|--------|-----------|-----------|
| 0 | [0,0] | 0.5 | **0.0** | 0.5 |
| 0 | [0,1] | 10.0 | 10.0 | 10.0 |
| 0 | [0,2] | 0.25 | **0.0** | 0.25 |
| 0 | [0,3] | 1.0 | **2.0** | 1.0 |
| 1 | [1,0] | 2.0 | 2.0 | 2.0 |
| 1 | [1,1] | -8.0 | -8.0 | -8.0 |
| 1 | [1,2] | 3.0 | **4.0** | 3.0 |
| 1 | [1,3] | 1.5 | 2.0 | **2.0** |

Sparse 在 channel 0 恢复了 0.5, 0.25, 1.0（被离群点 10.0 压碎的值），在 channel 1 将 3.0 从过估计的 4.0 修正为 3.0。
